Sistem Buku Tamu Digital (e-Visitor) dirancang khusus untuk Lembaga Pemasyarakatan Kelas IIA Kediri guna meningkatkan efisiensi, keamanan, dan kemudahan dalam pencatatan data pengunjung. Sistem ini memanfaatkan teknologi QR Code untuk mempercepat proses registrasi dan validasi.

- **Registrasi Mandiri (Self-Service)**: Pengunjung dapat mengisi data diri secara digital sebelum verifikasi.

- **Dashboard Admin yang Komprehensif**: Memantau statistik pengunjung, riwayat kunjungan, dan data tamu secara *real-time*.
- **Sistem Pelaporan Otomatis**: Membantu mempermudah rekapitulasi data untuk administrasi lembaga.
- **Desain Responsif**: Antarmuka yang ramah pengguna dan dapat diakses melalui berbagai perangkat (Desktop, Tablet, dan Mobile).

## 🛠️ Teknologi yang Digunakan

- **Frontend**: HTML, CSS, JavaScript
- **Hosting / Deployment**: Cloud Platform (Google Cloud Run / Hosting Service)
- **Database**: Relational Database Management System (RDBMS)
